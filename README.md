# رادار واعد 📡

بوت يراقب [صفحة مسار واعد](https://sites.moe.gov.sa/scholarship-program/paths/path-waaid/) في برنامج خادم الحرمين الشريفين للابتعاث، وينشر كل برنامج جديد في قناة تلقرام بكل تفاصيله، ويذكّر بمواعيد التقديم.

## ماذا يفعل

- **ينشر البرنامج الجديد كاملًا**: الشركة، الجهة التعليمية، الدولة، المدة، بداية الدراسة، فترة التقديم وحالتها (يبدأ بعد كذا / يُغلق بعد كذا)، والشروط في قسم مطوي، مع هاشتاقات للمجال والدرجة والدولة والشركة.
- **تذكيران لكل برنامج**: «بدأ التقديم اليوم» و«غدًا آخر يوم للتقديم». إذا كانت التذكيرات لعدة برامج في اليوم نفسه تصل في رسالة واحدة.
- **تحديث المواعيد**: إذا تغيّرت فترة التقديم (تمديد مثلًا) ينشر التحديث ردًّا على المنشور الأصلي ويعيد ضبط التذكير.
- **تنبيهات خاصة بك**: يرسل لمحادثتك فقط البرامج التي تهمك. الافتراضي هو مجالات الحاسب والبرامج التي تقبل خريجي الحاسب.
- **ملخص أسبوعي** كل أحد بالبرامج المفتوحة والقادمة، مع روابط منشوراتها.
- **ساعات هادئة**: من 11 مساءً إلى 7 صباحًا ينشر بدون إشعار ويؤجل التذكيرات إلى الصباح.
- **يراقب نفسه**: ينبهك إذا تعذّر الوصول للصفحة، أو لم يجد فيها برامج، أو نقص العدد فجأة.

## الإعداد (حوالي 10 دقائق)

1. **أنشئ البوت**: افتح [@BotFather](https://t.me/BotFather) في تلقرام، أرسل `/newbot`، واحفظ التوكن.
2. **أنشئ القناة**: قناة عامة باسم مستخدم مثل `@waaid_radar`، ثم أضف البوت **مشرفًا** مع صلاحية «نشر الرسائل».
3. **اعرف رقم محادثتك**: أرسل `/start` لبوتك، ثم افتح في المتصفح الرابط التالي (ضع توكنك مكان `<TOKEN>`):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   وخذ الرقم الذي بعد `"chat":{"id":`.
4. **ارفع المشروع** إلى مستودع على GitHub.
5. من المستودع افتح **Settings ← Secrets and variables ← Actions** وأضف:
   - في **Secrets**: ‏`TELEGRAM_BOT_TOKEN` = التوكن
   - في **Variables**: ‏`TELEGRAM_CHANNEL_ID` = `@اسم_قناتك`، و`TELEGRAM_ADMIN_CHAT_ID` = رقم محادثتك
6. من تبويب **Actions** اختر **waaid-radar** ثم **Run workflow**، وشغّل الأوامر بهذا الترتيب:
   - `check`: يتأكد من التوكن ومن أن البوت مشرف في القناة.
   - `preview`: يعرض في سجل التشغيل البرامج التي قرأها، بدون نشر. راجعه لتتأكد أن القراءة سليمة.
   - `run`: أول تشغيل. ينشر البرامج التي لم ينتهِ تقديمها، ويسجّل الباقي بصمت.

بعد ذلك يشتغل تلقائيًا **كل 3 ساعات**، ويرسل الملخص الأسبوعي **كل أحد 9 صباحًا** بتوقيت الرياض.

> **ملاحظة عن المستودع العام**: يوقف GitHub الجدولة في المستودع العام إذا مرّ 60 يومًا بلا نشاط. لتفادي ذلك يحدّث البوت ملف الحالة مرة على الأقل كل شهر. ومع ذلك فالمستودع الخاص (private) أضمن.

## الإعدادات

| المتغير | النوع | الوصف | الافتراضي |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Secret | توكن البوت | مطلوب |
| `TELEGRAM_CHANNEL_ID` | Variable | القناة: `@name` أو `-100…` | بدون قناة: كل شيء يذهب لمحادثتك |
| `TELEGRAM_ADMIN_CHAT_ID` | Variable | رقم محادثتك: التنبيهات الخاصة والأعطال | — |
| `PERSONAL_TAGS` | Variable | وسوم التنبيهات الخاصة مفصولة بفواصل، أو `*` للكل، أو `none` للإيقاف | `حاسب,لخريجي_الحاسب` |
| `QUIET_HOURS` | Variable | الساعات الهادئة بتوقيت الرياض، أو `off` | `23-7` |
| `SEED_POST_ACTIVE` | Variable | في أول تشغيل: نشر البرامج التي لم ينتهِ تقديمها | `true` |
| `RENDER_JS` | Variable | `false` أو `auto` أو `true`: قراءة الصفحة بمتصفح إذا صارت تحتاج JavaScript | `false` |

**بدون قناة؟** اترك `TELEGRAM_CHANNEL_ID` فارغًا، وتصلك في محادثتك البرامج التي تطابق `PERSONAL_TAGS` فقط (أو كلها إذا ضبطته على `*`).

## الهاشتاقات

- **المجال**: `#حاسب` ومعه التخصص الدقيق: `#ذكاء_اصطناعي` `#علم_البيانات` `#أمن_سيبراني` `#هندسة_البرمجيات` `#علوم_الحاسب` `#شبكات` `#نظم_المعلومات`. وللمجالات الأخرى: `#هندسة` `#طيران` `#أعمال_وإدارة` `#ضيافة_وسياحة` `#إعلام_وتصميم` `#صحة` `#قانون` وغيرها.
- **الدرجة**: `#ماجستير` `#بكالوريوس` `#دبلوم` `#تدريب` `#دكتوراه`
- **الأهلية**: `#لخريجي_الحاسب` للبرامج التي تقبل خريجي تخصصات الحاسب حتى لو لم يكن عنوانها في الحاسب (مثل برامج الروبوتات).
- **الدولة والشركة**: `#أستراليا` `#سنغافورة` `#STC` …

## التشغيل على جهازك أو على سيرفر

إذا كان موقع الوزارة يحجب خوادم GitHub، شغّل البوت من جهاز أو سيرفر داخل السعودية:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env              # ثم عبّئ القيم
python -m waaid_radar preview     # يعرض البرامج بدون نشر
python -m waaid_radar check --send-test
python -m waaid_radar run

# تجربة بدون نشر على صفحة محفوظة من المتصفح:
DRY_RUN=true python -m waaid_radar run --file page.html
```

ولتشغيله تلقائيًا أضف هذين السطرين إلى `crontab -e`. أوقات cron حسب ساعة السيرفر، والمثال يفترض أنها بتوقيت الرياض. أما البوت نفسه فيحسب المواعيد بتوقيت الرياض دائمًا:

```cron
17 */3 * * * cd /path/to/waaid-radar && .venv/bin/python -m waaid_radar run    >> radar.log 2>&1
7  9  * * 0  cd /path/to/waaid-radar && .venv/bin/python -m waaid_radar digest >> radar.log 2>&1
```

## كيف يعمل

1. يجلب الصفحة بطلب HTTP عادي. وإذا ضبطت `RENDER_JS` يستخدم متصفحًا كاحتياط.
2. لا يوجد في الصفحة هيكل ثابت للبيانات، لذلك يقسمها إلى برامج بالاعتماد على النص الظاهر. ويتعامل مع الحقول الملتصقة ببعضها، والمسافات المخفية، والأخطاء الإملائية في أسماء الحقول، والتواريخ بأشكالها المختلفة: أرقام هندية، و`23/7/2025`، وسنة مكتوبة مرة واحدة للمدى كله، ومدى يمتد إلى سنة جديدة.
3. يعطي كل برنامج معرّفًا ثابتًا من العنوان والشركة والجهة وبداية الدراسة. فإذا أعيد طرح برنامج في دورة جديدة يُعامل كبرنامج جديد، وإذا مُدّد موعده يُعامل كتحديث.
4. يحفظ ما نشره وما ذكّر به في `data/state.json`، ولا يعمل commit إلا إذا تغيّر شيء.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| «لم يجد أي برنامج في الصفحة» | غالبًا تغيّر تصميم الصفحة. اضبط `RENDER_JS` على `auto` ثم شغّل `preview` |
| «تعذّر جلب الصفحة» يتكرر | الموقع قد يحجب خوادم GitHub. شغّله من جهازك أو من سيرفر داخل السعودية (القسم أعلاه) |
| البوت لا ينشر في القناة | شغّل `check`: يجب أن يكون البوت مشرفًا بصلاحية النشر |
| فشل `git push` برسالة 403 | فعّل **Read and write permissions** من **Settings ← Actions ← General ← Workflow permissions** |
| توقفت الجدولة | فعّلها من تبويب **Actions**، أو اجعل المستودع خاصًا |
